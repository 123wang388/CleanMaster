# CleanMaster · 电脑清理与反流氓工具 v2

一个专门处理「360 全家桶 + 流氓软件 + 弹窗广告 + 磁盘垃圾」的 Windows 小工具。

写给不懂技术的朋友也能用：打开 → 点扫描 → 看结果 → 勾选 → 清理。每一步都能撤销。

---

## 七个页面

### 1. 概览 · 一键体检

一次扫描跑完五件事：360 残留、浏览器劫持、广告来源、可疑软件、磁盘垃圾。
结果分四张卡片，点「去处理」直达对应页面。

### 2. 360 专清

扫九个地方：进程、服务/驱动、启动项、计划任务、安装目录、注册表残留、右键菜单、浏览器扩展、系统策略。

每条都写明具体位置。另外提供「调用 360 官方卸载器」——能正常卸就别硬删，官方卸得更干净。

### 3. 浏览器修复 · 恢复原始状态

360 劫持浏览器就三招，这里全查：

- **快捷方式被加料**：`msedge.exe` 后面被挂了网址
- **组策略被写死**：`Policies\Microsoft\Edge` —— 这就是为什么你在 Edge 设置里怎么改都会被改回来，组策略优先级比用户设置高
- **用户配置被改**：主页、启动页、默认搜索引擎

v2 新增：

- **已装扩展检查**：不是从官方商店装的、又申请了通知权限或全网页读取权限的扩展会单独列出来
- **默认浏览器检查**：发现被 360 / 猎豹 / 搜狗占用会提示（这个设置受系统哈希保护，工具不硬改，只引导你去系统设置里改）
- **「彻底恢复原始浏览器」一键按钮**：清光所有组策略、重建配置、修复全部快捷方式、恢复 http/https/html 关联、隔离可疑扩展

> 修之前一定要**完全退出 Edge**（任务管理器结束所有 `msedge.exe`），否则它退出时会把内存里的设置写回去。

### 4. 广告查杀 · 让电脑不弹广告

重点说清楚：**现在电脑上的弹窗广告，大部分来自「网页通知」**。

某个网站被你允许发通知，关掉页面它照样弹。杀毒软件查不出来，因为那就是个正常网页。这里直接读浏览器的通知授权列表，把可疑站点一个个列出来，一键撤销。

其余来源也查：

| 检测项 | 说明 |
|---|---|
| 浏览器通知授权 | 网页弹窗广告的主要来源，标出非知名站点 |
| 计划任务 | 定时弹资讯/热点的任务 |
| 开机自启 | 推广程序的自启项 |
| 弹窗进程 | 正在跑的广告组件 |
| Windows 推荐广告 | 开始菜单建议、锁屏广告、静默装应用等开关 |
| hosts 劫持 | 被强制重定向的域名 |
| 购物导航快捷方式 | 桌面上双击就开购物页的那种 |

判定逻辑是「只认明确的广告特征」，不会把微软/Google/NVIDIA 的更新服务当广告——那种误报会让人误删系统组件。

### 5. 软件管理 · 卸载并清理残留

读注册表列出全部已安装软件，用关键词模型打分，把流氓软件单独标红。**每条都写明它为什么被判为流氓**，不是黑盒。

v2 重点：**卸载时顺带清干净**。

点「卸载并清理残留」→ 调起它自己的卸载程序 → 卸完点一下确认 → 自动扫残留：

- 安装目录 + AppData / LocalAppData / ProgramData 里的数据目录
- 注册表（`HKLM\SOFTWARE`、`WOW6432Node`、`HKCU\SOFTWARE`，支持厂商\产品两级）
- 开机自启项
- 系统服务
- 计划任务
- 桌面和开始菜单的快捷方式

扫出来是勾选列表，按风险预选，不想删的取消勾选。全部先备份。

> 在游戏平台目录（Steam / Epic / Tencent Games 等）里的组件默认不勾选，避免影响游戏。

### 6. 磁盘清理 · 所有盘都能看

四个子页：

- **垃圾清理**：临时文件、浏览器缓存、更新缓存、崩溃转储、回收站……按类统计体积
- **大文件**：扫全盘 100MB 以上的文件
- **空间分析**：目录树逐级展开
- **分盘盘点**（v2 重做）：**每个盘**单独一份档案

分盘盘点会告诉你每个盘：

```
C: 盘（总 336GB / 剩余 202GB）
  ├ 文件构成 —— 可执行程序 66.2GB、其他 31.8GB、代码工程 4.4GB、
  │              压缩包 3.0GB、游戏资源 2.9GB、安装包 1.9GB、图片 1.6GB…
  ├ 安装在这个盘的软件 —— 161 个，带发布者、体积、风险分
  ├ 大文件 —— 109 个 ≥100MB，可直接删到回收站
  └ 空间大头 —— 一级目录按占用排序
```

一次遍历同时算完这四样，C 盘 53 万文件约 1 分钟。

### 7. 恢复中心

每次清理生成一个备份批次，按批次一键回滚。注册表、文件、快捷方式、服务、浏览器配置都能还原。

## 安全设计

这工具动注册表和服务，所以做了三层保护：

1. **先备份再动手**。注册表用 winreg 递归导出 JSON——不依赖 `reg.exe`，被安全软件拦了也照样能备份；同时尽力再存一份 `.reg` 方便人工看。文件不删，移进隔离区。
2. **备份失败就取消**。某个项备份不成功，这个动作直接放弃，不会出现「删了但没备份」。
3. **系统组件保护**。System32、WinSxS、Fonts 等有保护名单；200+ 个系统核心服务（音频、RPC、电源、更新等）默认不列为残留；`AudioEndpointBuilder` 不会因为名字里有 "Build" 就被误判成某个带 "Build" 的软件。

## 怎么用

### 方式一：直接跑 exe（给朋友用）

双击 `CleanMaster.exe`，右键「以管理员身份运行」效果最好。

### 方式二：用 Python 跑

```bat
python app.py
```

需要 Python 3.8+ 且带 tkinter。

### 建议顺序

1. **概览** → 开始体检，先看全貌
2. **360 专清** → 先调官方卸载器卸主程序，再扫残留
3. **浏览器修复** → 关掉 Edge，点「彻底恢复原始浏览器」
4. **广告查杀** → 重点看「浏览器通知」那几项
5. **软件管理** → 清理其他流氓软件（会自动扫残留）
6. **磁盘清理** → 最后清垃圾
7. 出问题 → **恢复中心** → 选批次 → 还原

## 注意事项

**必须用管理员权限**
清理服务、驱动、HKLM 注册表都需要管理员。右上角有「以管理员身份重启」。普通权限也能扫描，只是系统级项目清不掉。

**360 的自我保护**
360 开着自保护时进程和服务删不掉。先在 360 里关掉自保护，或直接走官方卸载器。

**哪些不会动**
- 不碰用户文档、照片、工作文件
- 不碰系统关键目录
- 虚拟内存文件只提示，不建议删
- 不常驻后台、不加壳、不静默更新

## 说明

关键词识别是启发式的：命中厂商特征、无卸载入口、可疑安装路径等会给分，够高就标红。**它会给理由**，每个软件都能看到命中了哪几条特征。

发现误判改这里：
- `core/rules.py` 的 `WHITELIST_VENDORS` / `VENDOR_RULES` — 软件识别
- `core/mod_ads.py` 的 `AD_STRICT` / `AD_FAMILIES` — 广告特征

数据目录在 exe 同级 `CleanMasterData/`：
```
backups/     每次清理的备份批次
quarantine/  被移走的文件
logs/        运行日志
```
